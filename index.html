使用方式建議

手機、平板（最簡單）
用 Chrome（Android）或 Safari（iOS 26 以上）以 https 網址開啟本工具 → 「硬體與推薦」選一個綠色標示的模型 → 下載完成後就能開飛航模式使用。iPhone 用 Safari「分享 › 加入主畫面」可像 App 一樣開啟。直接點開手機裡的 HTML 檔，部分瀏覽器會停用 WebGPU 或儲存功能（不確定，依瀏覽器而異）。
電腦（效能最好）
安裝 Ollama → 在「模型下載」輸入模型名稱下載 → 對話頁引擎選 Ollama。若出現連線被拒（CORS），請設定環境變數 OLLAMA_ORIGINS（見下方）後重啟 Ollama。也可用 llama.cpp 的 llama-server 或 LM Studio 的本機伺服器。
Ollama 連線被拒（CORS）怎麼辦
Ollama 預設只接受 127.0.0.1／0.0.0.0 來源的網頁。若本工具是用其他網址或直接開啟檔案，請設定：
Windows（PowerShell）：setx OLLAMA_ORIGINS "*" 後從工作列結束 Ollama 再重開
macOS：launchctl setenv OLLAMA_ORIGINS "*" 後重開 Ollama App
Linux（systemd）：sudo systemctl edit ollama 加上 Environment="OLLAMA_ORIGINS=*"
「*」代表允許所有網頁連線，若電腦會連公共網路，建議改填本工具的實際網址來源。
